# Мобильный доступ и PWA

## Что это

На странице роутера, во вкладке **JanusNew**, можно создать QR-код для входа
с телефона. QR ведёт на страницу установки PWA. После входа пользователь
может менять правила, подключения, DNS и перезапускать службу — в пределах
прав владельца роутера.

## Как работает

1. Владелец открывает роутер → **JanusNew** → **«Создать QR для телефона»**.
2. Сервер создаёт одноразовый токен на **5 минут** и возвращает QR.
   Предыдущие неиспользованные QR для этого роутера отзываются.
3. Телефон открывает `/#/install?token=…&router=…`.
   Токен находится во фрагменте URL и не попадает в логи и Referer.
4. Страница установки сразу обменивает токен на обычную сессию:
   `POST /api/v1/mobile/exchange`.
5. Токен помечается использованным. Повторно открыть ссылку нельзя.
6. На телефоне показывается установка PWA и кнопка «Открыть роутер».

## Безопасность

* В базе хранится только SHA-256 токена.
* Токен одноразовый, TTL 5 минут.
* Создать токен может только владелец роутера или суперадминистратор.
* Обмен токена создаёт обычную сессию с cookie; дальше действуют обычные
  правила сессии и CSRF.
* Действия логируются: `router.mobile_token`, `auth.mobile_login`.
* Если `RC_COOKIE_SECURE=false`, но вход идёт по HTTPS, cookie мобильной
  сессии всё равно ставится с флагом Secure.
* Просроченные и использованные токены удаляются retention-сервисом.

## PWA и HTTPS

Для установки PWA на iPhone/Android нужен **HTTPS**. В лабораторном HTTP-
режиме QR откроет панель, но установка приложения может быть недоступна.

* Manifest: `/manifest.webmanifest`.
* Иконки: `/icons/icon-192.png`, `/icons/icon-512.png`, maskable-вариант.
* Service worker: `/sw.js`, кэширует только оболочку; `/api/` и `/agent/`
  не кэшируются.
* QR использует **текущий origin**, по которому открыта панель. Если открыть
  панель по HTTPS-домену, QR будет HTTPS и PWA установится.
* `RC_PUBLIC_URL` по-прежнему используется для ссылок приглашений и команд
  установки агента; для QR он нужен только если у запроса нет Origin
  (например, создание через API/curl).

## Ограничения

* Это доступ **владельца**, а не отдельная роль «член семьи». Для
  ограниченного доступа нужно отдельное проектирование ролей.
* Ссылка одноразовая: для второго телефона создайте новый QR.
* Если ссылка истекла, страница установки предложит обычный вход.
