# E2E (Playwright)

Каркас браузерных тестов лежит в `e2e/`, конфиг — `playwright.config.ts`.

Запуск против уже поднятой панели:

```bash
npm run test:e2e
# или против конкретного адреса:
PLAYWRIGHT_BASE_URL=https://routx.example.com npm run test:e2e
```

Первый раз нужно поставить браузер:

```bash
npx playwright install chromium
```

Сейчас покрыт smoke: вход и корень без сессии. Дальше добавляются сценарии с
тестовым пользователем: создание роутера, секции, Wi-Fi, обновление агента.
В CI джоб не подключён: нужен отдельный тестовый инстанс с Postgres и
одноразовым пользователем без 2FA.
