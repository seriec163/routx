# Контракт пользовательского API

Машинночитаемое описание: `docs/architecture/api-openapi.json` (OpenAPI 3.1).
Агентский протокол — отдельно, в `docs/architecture/agent-openapi.json`.

Пересобрать:

```bash
npm run contract:api
```

Что внутри:

* все маршруты `/api/v1` и `/metrics` (индекс собирается из Fastify через
  `onRoute`, поэтому новый маршрут попадает в контракт автоматически);
* `security`: cookie `rc_session`; для `POST/PUT/PATCH/DELETE` нужен заголовок
  `x-csrf-token` из cookie `rc_csrf`;
* подробные схемы для ключевых эндпоинтов: вход, роутеры, `refresh`, `diff`,
  Wi-Fi, задачи, логи, deploy, метрики;
* общая схема ошибок `Error` и задачи `Job`.

Ограничение: схемы запросов остальных маршрутов пока описаны как свободный
объект. Их уточняем по мере выноса Zod-схем из обработчиков. CI проверяет, что
сгенерированный файл закоммичен в актуальном виде.
